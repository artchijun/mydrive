Mydrive

Mydrive 는 개인 NAS 와 휴대폰을 잇는 탭 방식 파일 탐색기입니다. 휴대폰 저장소, 집 NAS(Mydrive 서버), 그리고 사용자가 직접 연결한 클라우드 저장소(Google Drive, OneDrive)의 파일을 한 앱에서 보고 옮길 수 있습니다.

Mydrive is a tabbed Android file explorer for a personal NAS. It browses phone storage, the user's own NAS server, and cloud drives (Google Drive, OneDrive) that the user connects.
